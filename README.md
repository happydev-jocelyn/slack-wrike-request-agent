# slack-wrike-request-agent

Slack 채널에서 받은 업무 요청을 Wrike 티켓(검토중)으로 등록하고, 지정된 승인자가 ✅로 확정하면 Wrike '전체 일감' 폴더에 일감을 만드는 Slack 앱입니다. 일감의 정본은 Wrike이고, 앱은 일감 데이터를 따로 저장하지 않습니다.

## 현재 상태

| 단계 | 내용 | 상태 |
|---|---|---|
| M1 | 요청 등록 → Wrike 티켓(검토중) → ✅ 확정·❌ 반려, 여러 등록 입구, 실패 처리 | 구현·테스트 완료 (가짜 Wrike로 실행 확인) |
| M2 | AI(Claude)가 기존 티켓·일감과 비교한 의견을 스레드와 Wrike 댓글에 남김 | 예정 |
| M3 | 앱 홈 탭 설정 화면(토큰·프로젝트·워크플로를 이름 또는 ID로), Docker 실행 | 예정 |
| M4 | 실제 Wrike 계정으로 연동 확인 | 예정 |

지금은 설정을 환경변수로 넣습니다(M3에서 Slack 홈 탭 설정으로 바뀝니다). 실제 Wrike 계정으로는 아직 확인하지 않았습니다.

명세(인수조건)와 진행 상황은 [이슈 #2](https://github.com/happydev-jocelyn/slack-wrike-request-agent/issues/2)에 있습니다.

## 사용법

### 요청하는 사람
요청 채널에서 아래 중 편한 방법으로 폼을 열고 카테고리·일감 제목·일감 내용·담당자를 입력합니다.

- 채널에 고정된 **요청 등록** 버튼
- 채널에 그냥 글을 쓰면 본인에게만 보이는 **"Wrike 요청으로 등록할까요? [등록]"** 안내 → 글 내용이 미리 채워진 폼
- 아무 메시지의 ⋯ 메뉴 → **Wrike 요청으로 등록** (그 메시지 내용이 미리 채워짐)
- 입력창 ⚡(단축키) 메뉴 → **요청 등록**
- `/request` 명령

등록하면 Wrike '요청' 폴더에 '검토중' 티켓이 생기고, 요청 채널에 "새 요청 · 검토중" 메시지가 Wrike 링크와 함께 올라옵니다. Wrike 티켓에도 Slack 메시지 링크가 남습니다. Wrike 등록이 실패하면 아무것도 게시되지 않고 요청자에게만 이유가 보입니다.

### 승인자
"새 요청" 메시지에 이모지를 누릅니다.

- ✅ 확정: 티켓이 '확정'이 되고 '전체 일감' 폴더에 일감이 생기며, 스레드에 일감 링크가 달립니다.
- ❌ 반려: 티켓이 '반려'가 되고 스레드와 Wrike 댓글에 반려자가 기록됩니다.

승인자가 아닌 사람이 누르면 그 사람에게만 "권한 없음"이 보입니다. Wrike에서 이미 처리되었거나 삭제된 요청은 바꾸지 않고 스레드에 현재 상태를 알립니다.
